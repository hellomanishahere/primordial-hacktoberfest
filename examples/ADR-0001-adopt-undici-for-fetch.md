# ADR-41749-01: Add Fetch globals behind an experimental flag

## Context

The pull request adds a Fetch API implementation to Node.js.

## Decision Outcome

The change adds a `--experimental-fetch` flag that installs the `fetch`, `Request`, `Response`, and `Headers` globals. The pull request was merged on February 1, 2022.
