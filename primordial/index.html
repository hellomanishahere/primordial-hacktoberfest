ACCEPTED DECISION ● 98.2% High Confidence Target: v1.28 • PR: #112948

Adopt Soft Eviction Grace Period with Cgroups v2 Memory Pressure Stalls (PSI) instead of Hard Kill

Author: Alexandre Cesena (@acesena) • SIG: sig-node • Kubelet Core Subsystem
💡 Why This Decision Was Made SEMANTIC SYNTHESIS
CORE ARCHITECTURAL RATIONALE

Hard eviction thresholds triggered cascading pod terminations under transient burst loads. By utilizing Cgroups v2 PSI (Pressure Stall Information), Kubelet can measure actual memory thrashing before executing SIGKILL.

🛡️ Supporting Arguments
  • Reduces spurious job evictions by 74% during batch ML workloads.
  • Native kernel PSI metrics avoid periodic procfs polling overhead and CPU latency spikes.
  • Deterministic telemetry pipeline shared uniformly with containerd runtime.
⚠️ Opposing Arguments & Concerns
  • Requires Linux kernel >= 5.8 on all cluster nodes, complicating legacy distro rollouts.
  • Slightly delayed reaction (500ms grace window) under catastrophic sudden memory spikes.
  • Initial backward-compatibility burden for clusters running hybrid cgroups v1 nodes.
🛑 Recovered Rejected Alternatives
2 Candidate Paths Abandoned
REJECTED Static 10% headroom reservation

Rejected due to severe resource under-utilization in high-density multi-tenant nodes. Wasted up to 64GB RAM per HPC bare-metal box.

REJECTED Userspace OOM daemon (systemd-oomd integration)

Rejected due to unresolvable race conditions with container runtime shim during high socket stress events.

📉 Telemetry Footprint Drop

Memory telemetry overhead reduced by 18MB per worker node.

🔗 Topology Dependency

Requires strict cgroupv2 systemd unified hierarchy mount points.
